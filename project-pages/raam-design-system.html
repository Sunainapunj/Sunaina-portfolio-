RA.A.M UX Design System

Design Systems · Scalable UI Architecture

Overview

RA.A.M is a proposed modular design-system architecture built around a shared foundation of reusable UI components, interaction patterns, design tokens, and accessibility principles.

The core system will serve as a common foundation. On top of it, four domain-specific design systems will be developed, each adapting the shared foundation to the needs, workflows, terminology, and interaction requirements of its own domain.

Proposed architecture · PROPOSED DIRECTION, UNDER DEVELOPMENT

RA.A.M Core

  • Reusable UI components

Why domain-specific systems?

Each domain has its own workflows, terminology, regulatory context, and user expectations. A shared core keeps products consistent and accessible, while domain systems allow specialised components, patterns, and visual decisions without forking the foundation.
